## 🚀 DÉPLOIEMENT

### Installation Rapide (5 minutes)
```bash
# 1. Cloner
git clone https://github.com/votrecompte/batisaas.git
cd batisaas

# 2. Installer (via navigateur)
# Visitez: http://votre-domaine.com/install.php

# 3. C'est fait ! 🎉
```

### Ou installation manuelle
```bash
# Configuration BDD
nano config/database.php

# Import schéma
mysql -u root -p batisaas < database/schema.sql

# Exécuter migrations
php database/migrate.php up

# Données de test (optionnel)
php scripts/seed.php
```

### Docker (à venir)
```bash
docker-compose up -d
```
